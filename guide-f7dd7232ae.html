ONECUE

원큐 시험 매뉴얼

11-02 기준입니다. 광고주 화면에서 바뀐 부분과 원큐가 영상을 만드는 방식을 설명합니다. 이어서 광고주 아이디로 직접 의뢰해 보고, 관리자 아이디로 확인·납품까지 해 보는 순서를 처음부터 끝까지 정리했습니다.

한눈에

  • 광고주 아이디(sh@onecue.kr · psw@onecue.kr)로 의뢰하면 승인 없이 끝까지 자동으로 만들어집니다. 아이디마다 새 의뢰 4건까지입니다.
  • 관리자 아이디(sh1@onecue.kr · psw1@onecue.kr)로 결과를 확인하고, 고치기 요청을 넣고, 광고주에게 전달(납품)까지 합니다.
  • 의뢰부터 확인 요청 알림까지 보통 30~40분입니다.

1. 바뀐 부분 — 「연출 스타일」

의뢰서 2단계 이름이 「영상 분위기」에서 「연출 스타일」로 바뀌었습니다. 화면 제목은 「제품에서 눈길을 확 끄는 장면 하나를 만들어 드립니다」입니다. 고르는 칸은 세 가지입니다.

추천

원큐에게 맡기기

제품과 톤을 보고 원큐가 두 가지 중 하나를 고릅니다. 고른 이유는 기획서에 남습니다.

기발하고 유쾌하게

제품의 성질이 세상의 규칙이 되는 식의 재치 있는 장면입니다. 밝고 귀여운 쪽입니다.

크고 시원하게

방이나 거리 전체가 바뀌는 큰 장면입니다. 압도하고 감탄하게 하는 쪽입니다.

2. 원큐가 만드는 방식 — 「강한 장면 하나」

15초 안에 여러 장면을 나열하지 않습니다. 제품이어야만 성립하는 강한 장면 하나를 만듭니다. 파도 서핑이나 환타 회오리 같은 장면입니다. 첫 1초 안에 바로 변화가 시작되고, 가운데에 가장 크고 긴 정점이 오고, 끝은 제품과 로고로 맺습니다.

기발하고 유쾌하게

오아 손 선풍기

무더위에 축 처진 공원에서 손바닥만 한 선풍기를 켜는 순간, 그 바람이 공원 전체의 규칙이 되어 세상이 시원하게 살아납니다.

크고 시원하게 · 맡기기에서 원큐가 고름

꼼뚜 압화 항아리 캔들

캔들 윗면의 마른 압화가 깨어나 고요한 방 전체를 정원으로 피워 냅니다.

원큐가 혼자 하는 일

  1. 브리프 — 판매 페이지를 읽고 실물 사진을 찾아 정답 사진을 고릅니다. 대상, 가격대, 공식 로고·문구도 확인합니다.
  2. 기획 — 연출 스타일에 맞는 장면 하나를 정하고, 버린 후보와 그 이유, 15초 흐름을 씁니다.
  3. 참조 그림 — 제품 시트(실물과 대조해 통과해야 씀), 인물, 장소를 만듭니다.
  4. 영상 — 15초를 생성합니다.
  5. 후반 — 엔드카드 후보 여러 개를 만들고 점수로 하나를 골라 얹습니다.
  6. 게시 — 관리 화면에 확인 요청을 올리고 알림을 보냅니다.

4. 시뮬레이션 ① 광고주 아이디로 의뢰하기

  1. 로그인 — 원큐 첫 화면 오른쪽 위 「지금 바로 만들기」를 누르거나 로그인 화면에서 광고주 아이디(sh@ 또는 psw@)로 들어갑니다.
  2. 1단계 · 기본 정보 입력 — 상호/브랜드명, 제품 종류, 제품 이름, 가장 자랑하고 싶은 특장점을 씁니다. 피하고 싶은 느낌과 참고 영상은 비워 둬도 됩니다.
  3. 2단계 · 연출 스타일 — 세 가지 중 하나를 고릅니다. 처음에는 「원큐에게 맡기기」를 권합니다.
  4. 3단계 · 사진 등록 & 비즈니스 링크 — 제품 사진 1~3장(필수)과 판매 페이지 주소를 넣고 「주소 확인」을 누릅니다.
    판매 페이지는 공식몰이나 컬리 같은 일반 페이지가 가장 잘 읽힙니다. 네이버 스마트스토어는 로그인 화면으로 막히는 일이 많습니다. 막혀도 원큐가 웹에서 실물 사진을 찾아 진행하지만, 공식몰이 더 정확합니다.
  5. 4단계 · 영상 화면 비율 선택 — 올릴 채널(비율)을 고릅니다.
  6. 5단계 · 입력 내용 확인 & 영상 생성 — 줄마다 확인 체크를 하면 「영상 생성 시작」이 켜집니다. 누르면 끝입니다.
  7. 진행 화면 — 「영상 제작 진행 중」과 예상 소요 시간이 나옵니다. 창을 닫아도 원큐는 계속 만듭니다.

누른 뒤 일어나는 일 (실측 예: 오아 선풍기)

0분접수 — 텔레그램 「새 의뢰」 알림
~15분브리프 — 판매 페이지·실물 사진 조사
~20분기획 — 장면 하나·15초 흐름
~30분참조 그림·영상·후반(약 10분)
~35분게시 — 텔레그램 「완성 · 확인 요청」 알림

중간에 멈추면 텔레그램 「멈춤」 알림이 원인과 함께 옵니다. 그때는 Dan 께 알려 주세요.

광고주 화면에는 납품하기 전까지 완성 영상이 뜨지 않습니다. 관리자가 확인하고 「최종 컨펌」을 눌러야 광고주 화면에 완성 영상이 올라갑니다(다음 ②).

5. 시뮬레이션 ② 관리자 아이디로 확인·납품하기

  1. 로그인 — 로그아웃한 뒤 관리자 아이디(sh1@ 또는 psw1@)로 들어갑니다. 텔레그램 알림에 있는 「관리 화면」 주소를 눌러도 됩니다.
  2. 제작 관리 — 왼쪽 메뉴 「제작 관리」에서 건을 엽니다. 맨 위 「납품 전 확인 요청」에 완성 영상과 의뢰부터 걸린 시간이 있습니다.
  3. 엔드카드 바꾸기(필요할 때) — 「엔드컷 후보」 중 다른 것을 누르면 코드가 바로 바꿔 다시 올립니다. 크레딧은 들지 않습니다.
  4. 고치기 요청(필요할 때) — 고칠 곳 하나를 고르고 메모를 쓰면 엔진이 그 범위만 다시 합니다.
    • 엔드컷·글자 / 로고·문구 — 크레딧 0, 바로 다시 올라옵니다.
    • 영상만 다시 / 기획부터 다시 — 크레딧이 들어서 「생성 승인」 버튼이 뜹니다. 눌러야 생성합니다.
  5. 최종 컨펌 · 광고주에게 전달 — 연두색 버튼입니다. 확인 창에서 한 번 더 누르면 이 순간이 납품이고, 1분 안에 광고주 화면에 완성 영상이 뜹니다.
  6. 광고주 화면 확인 — 다시 광고주 아이디로 들어가 그 의뢰를 열면 「완성 영상」과 「영상 내려받기」가 보입니다.
관리 화면의 다른 버튼은 시험할 때 누르지 않아도 됩니다. 「이 건 다시 설계하기」는 처음부터 다시 만드는 버튼입니다. 엔진이 멈춘 건에만 씁니다.

6. 시험 끝나고 알려 주실 것

  • 연출 스타일을 무엇으로 골랐고, 결과가 그 느낌이었는지
  • 제품 생김새(색·모양·로고)가 실물과 같은지
  • 멈춤 알림이 왔는지, 왔다면 그 내용
  • 의뢰서나 관리 화면에서 헷갈렸던 곳

이 페이지는 시험용 임시 페이지입니다(검색에 나오지 않음).
