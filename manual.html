옵션 1 · 옵션 2

같은 의뢰를 두 가지 방식으로 만들 수 있습니다. 관리자가 의뢰 접수 때 고르고, 콘셉트를 고른 뒤에는 바꿀 수 없습니다.

옵션 1 · 콘티 방식

장면을 콘티로 그려 광고주와 먼저 맞춘 뒤, 그대로 영상으로 만듭니다.

  • 10단계: 구성·각본 → 콘티 → 제작 자료 → 영상
  • 광고주가 장면을 미리 보고 확정
  • 콘티에 묶여 밋밋해지기 쉬움

옵션 2 · 브리프 방식

목표와 조건만 적은 브리프 한 장을 주고, 컷 구성은 AI가 직접 설계합니다.

  • 8단계: 콘셉트 → 제작 자료·브리프 → 영상 (구성·각본·콘티 없음)
  • AI가 브리프 초안을 쓰고, 관리자는 고칠 곳만 고침
  • 인물 확인만 하면 영상까지 자동

광고주 화면

  1. 새 프로젝트 → 의뢰서 쓰기브랜드·제품 이름, 제품 설명, 사진, 하고 싶은 것, 대상, 원하는 화면 느낌(예시 그림에서 고름), 게시할 매체, 길이를 적고 보냅니다.
  2. 콘셉트 선택관리자가 보낸 콘셉트 5안 중 하나를 고릅니다. 마음에 드는 게 없으면 추가 요청을 할 수 있습니다.
  3. 콘티 확인 (옵션 1만)장면별 콘티를 보고 승인하거나, 고칠 곳을 적습니다.
  4. 납품 확인완성본을 보고 확인했습니다 · 승인 또는 고쳐주세요를 누릅니다.

진행 중에는 위쪽 막대에서 지금 어느 단계인지 보입니다. 광고주는 자기 의뢰만 볼 수 있습니다.

관리자 화면

주소 onecue26.github.io/admin.html. 의뢰 카드를 펼치면 「전체 제작 흐름」에 단계가 줄지어 있고, 지금 단계 칸에 누를 버튼이 하나씩 뜹니다. 위에서부터 차례로 누르면 됩니다.

옵션 2로 끝까지 가는 순서

  1. 의뢰 접수의뢰 내용을 보고 옵션 2를 고른 뒤 의뢰를 확정합니다.
  2. 제품·자료 확인 · 전략 설계 무료AI가 써 둔 결과를 보고 승인합니다.
  3. 콘셉트 5안 무료5안을 보고 광고주에게 보내기. 광고주가 하나를 고르면 다음으로 넘어갑니다.
  4. 제작 자료 · 브리프 인물 1명당 약 6crAI가 브리프 초안을 채워 둡니다. 고칠 곳만 고치고 브리프 저장을 누르면 크레딧 확인 창이 뜨고, 확인하면 등장인물 기준 그림이 만들어집니다. 그림을 보고 승인.
  5. 영상 제작 한 판 45cr인물 그림을 승인할 때 크레딧 확인 창이 뜨고, 확인하면 영상 한 판이 시작됩니다(시댄스 2.5 · 15초 · 480p). 다 되면 보고 승인 → 다음 단계로. 다시 만들 때는 의견 → 답변 → 이 답변대로 → 다시 뽑기.
  6. 후반 작업 무료AI에게 맡기기 → AI 작업 시작. 자막·끝 화면을 입힌 완성본이 나옵니다. 고칠 점은 의견 칸에 적으면 크레딧 없이 바로 다시 만듭니다.
  7. 납품승인하고 광고주에게 납품을 누르면 광고주 화면에 완성본이 뜹니다.

옵션 1은 3번 뒤에 구성·각본 → 콘티(광고주 승인)가 들어가고, 제작 자료·영상은 관리자가 직접 눌러 시작합니다.

막힐 때

  • 버튼을 눌렀는데 아무것도 안 보인다 — AI가 만드는 중입니다. 글은 1~10분, 영상은 5~15분 걸립니다. 화면을 새로 읽어 보세요.
  • 영상이 안 보이는데 승인 버튼만 있다 — 자동 검수 중입니다(2~5분). 영상이 뜬 뒤에 보고 승인하세요.
  • 버튼이 회색으로 잠겨 있다 — 앞 단계가 끝나지 않았거나 생성 중입니다. 옆에 이유가 적혀 있습니다.
  • 결과가 이상하다 — 승인하지 말고 의견 칸에 무엇이 어떻게 이상한지 적으세요. 답변을 보고 정하면 됩니다.
